What it does

Client feedback rounds

Applies the client's notes or Figma comments, copy exactly as supplied, in a new version so the original stays untouched.

Inner pages

Builds new pages from the file's existing components, styles and the client's copy document.

Tablet and mobile versions

Adapts approved desktop pages using the client's breakpoints, variables and boilerplate.

Components and states

Hover, focus and disabled states, dropdowns and prototype links, after checking how many screens a change affects.

Images from the right source

Uses each client's image preference (iStock, Adobe Stock, client photos, Dropbox links) and logs what needs buying.

Audits

Consistency, Content and Accessibility (WCAG 2.2 AA) audits that report issues page by page and never change the file.

What happens on every job

  1. Finds the client and their SOP

    Recognises the agency or project from the link or name, and loads its rules: versioning, breakpoints, copy rules, image source, delivery tool.

  2. Reminds the designer of the client's preferences

    For example: "Digital Attic image preference: Depositphotos, then Envato". If a client works in their own Figma account, it says so at the start and at the end.

  3. Takes a before snapshot

    Records the page so it can prove afterwards that nothing outside the linked frame changed.

  4. Makes only the requested change

    Inside the linked frame, using the file's own components, styles and variables. It never substitutes fonts and asks before deleting anything.

  5. Verifies its own work

    Screenshots, a read-back of every changed text, missing-font check, and a before/after comparison of the rest of the page.

  6. Reports in three formats

    A designer report with a checklist, a Slack update for the team, and a client message with Figma prototype links.

  7. Files everything by person, client and project

    Job log, snapshots, assets, audits and cost go into that project's folder, so the next job starts with the full history.

Benefits for the business

Faster turnaround

Typical maintenance jobs finish in 4 to 8 minutes of agent time. A full new landing page with tablet and mobile versions took 23 minutes before designer review.

Every client's rules applied, every time

178 agency SOPs, built from teaming.rocks and our client sheet, load automatically when a client is named. Nobody has to remember who uses Adobe Stock or which breakpoints Digital Drive needs.

Consistent quality checks

Copy is diff-checked against the client document, fonts and spacing are verified, and three audit types catch inconsistencies, typos and accessibility issues before the client sees them.

Safe on client files

It edits only the linked frame, never deletes pages, asks before deleting layers or changing shared components, and logs every action it takes in Figma.

Clearer client communication

Every job ends with a client-ready message in our house format: what we did, each page with its prototype link, a note on placeholders, and thank you.

Knowledge stays in the company

Corrections and client rules are saved centrally and shared with the whole team in each plugin version, so a new designer starts with everything the team has learned.

Transparent cost

Token usage and cost are recorded per task, per project and per client, for estimating and billing.

Safety and governance

  • Edits only the frame or section in the link, never the rest of the file.
  • Never deletes pages; asks before deleting layers, detaching components or changing shared styles.
  • Audits are read-only by design and blocked from writing.
  • Every Figma action is logged with time, file and person.
  • One SOP manager owns the client rules; co-workers send proposals for review.
  • Client content is never sent to outside services; access keys are stored in the Mac Keychain.
  • Instructions hidden in client files or comments are treated as content, not commands.
  • Versioned in Git and published on GitHub, so every release can be rolled back.

What still needs a designer

The agent does the repetitive production work; designers keep the judgement. They approve every round before it goes to the client, handle image editing and retouching, buy the stock images that get approved, fix fonts that aren't installed, and own the client relationship.
